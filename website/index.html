使用时只记三句 Three rules

远程不是另一套网盘，只是你自己的 GitHub 或 Gitee 仓库。Pixuli 不提供一键发布。 The remote is your own GitHub or Gitee repository, not another drive. Pixuli does not publish files for you.

  1. 01

    改库，只动本机 Edit on this machine

    添加、删除和移动都不会自动上传。 Adding, deleting, or moving a file does not upload it.

  2. 02

    要远端一样，点同步 Sync when you want a match

    拉取和推送都由你发起，库不会因此被锁住。 You start every pull and push. The library stays usable.

  3. 03

    要给人看，复制链接 Copy a link to share

    还只在本机的文件需要先同步。别人能否打开，取决于仓库是不是公开的。 A local-only file has to be synced first. Whether the link opens depends on the repository being public.

工作区里做这些事 What the workspace does

资源库 Library
文件夹、搜索、列表和详情在同一页。角标只区分「仅本地」和「已同步」。 Folders, search, the list, and the inspector share one page. A badge says local-only or synced.
同步 Sync
活动栏显示还有多少文件待推送。同步进行时仍可继续浏览。 The activity bar shows how many files are waiting to push. You can keep browsing.
外链 Links
没有连接、文件仍在本地，或仓库是私有的，都会直接说明，而不是给一个打不开的地址。 If there is no connection, the file is still local, or the repository is private, Pixuli says so instead of handing out a dead link.
连接 Connections
在设置里添加 GitHub 或 Gitee，使用个人访问令牌。 Add GitHub or Gitee in Settings with a personal access token.
工具 Tools
压缩和格式转换的结果写回本机，不会顺便推到远端。 Compress and convert write back to the local folder. They do not push.
外观 Appearance
跟随系统，或自己选浅色与深色。网页、桌面和手机用同一套界面。 Follow the system, or pick light or dark. Web, desktop, and Android share the interface.

三端同一套界面 One interface, three places

  • Web

    在浏览器里打开，也可以安装到桌面。 Use it in the browser, or install it on the desktop.

  • Desktop

    macOS 与 Windows。选择本机文件夹作为工作区。 macOS and Windows. Pick a local folder as the workspace.

  • Android

    手机上继续浏览同一个库，安装包在发布页。 Browse the same library on a phone. The package is on the releases page.

从网页版看一眼，或装到自己的电脑上 Try it in the browser, or install it

网页版无需安装。桌面版和 Android 安装包按版本放在 GitHub Releases。 The web app needs no install. Desktop and Android builds are on GitHub Releases.
