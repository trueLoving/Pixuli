# Pixuli 使用指南

本地优先的资源工作区：本机整理文件，需要时同步到 GitHub /
Gitee，要给人看时复制链接。

更细的产品规则见 [product.md](./product.md)。开发运行见根
[README.md](../README.md)。

---

## 一、只记三句

1. **改库 = 只动本机**（添加、删改、移动、处理都不自动上云）
2. **要远端一样 → 点同步**
3. **要给人看 → 复制链接**（仅本地时先同步；外人能否打开取决于仓库是否公开）

北极星：本机整理配图 → 同步到公开仓 → 复制 raw 链接贴进 Markdown。

---

## 二、快速开始

1. 打开 Pixuli（[在线 Demo](https://pixuli-web.vercel.app/) ·
   Releases 里的 Desktop / Android）。
2. **打开或创建本地工作区**（本机文件夹是真相源）。
3. **添加文件**到当前文件夹（仅本机；不是「上传到云」）。
4. **设置 → 同步**：用统一向导添加 GitHub 或 Gitee 连接（PAT 只存在本机）。
5. 活动栏点 **同步**，把本机与远端对齐。
6. 需要外链时点 **复制链接**。

博客配图建议用**公开**仓库，否则 raw 链接外人往往打不开。

---

## 三、连接 GitHub / Gitee

在设置的同步分区走统一向导（新增、编辑、空态入口相同）。

### GitHub

1. 建仓库（配图场景建议 Public）。
2. Settings → Developer settings → Personal access tokens → 生成 classic
   token，勾选 `repo` / `public_repo`。
3. 在向导中填写 owner、仓库、分支、路径、Token 并保存。

### Gitee

1. 建公开或私有仓库。
2. 设置 → 安全设置 → 私人令牌，勾选仓库相关权限。
3. 同样在向导中填写并保存。

Token 不会上传到 Pixuli 官方服务（产品没有官方后端）。

## 四、资源库日常

| 动作                 | 说明                                                 |
| -------------------- | ---------------------------------------------------- |
| 浏览                 | 始终在一个文件夹里；面包屑可返回；子文件夹在文件上方 |
| 搜索                 | 支持查询语法；可「在全部中搜索」                     |
| 角标                 | **仅本地** / **已同步**                              |
| 预览                 | 图片、视频、PDF                                      |
| 移动 / 删除 / 改信息 | 仅本机，不同步删远端                                 |
| 下载                 | 检查器可下载文件（Android 写入系统下载目录）         |

不要在界面上找「发布」——外链就是复制链接。

---

## 五、处理（图片）

本地工作区选中图片后，详情或批量操作里点 **处理**：

- **裁剪**：选区保存为旁边的新文件（如 `cover-crop.png`），仅本机
- **转换**：WebP / JPEG / PNG、质量、长边等；结果写回原文件夹，仅本机

压缩写回工作区尚未接入处理弹窗。PDF / 视频 /
Markdown 的深加工尚未提供；没有能力时不会出现假入口。

## 六、三端差异（用户侧）

|                | Web                          | Desktop        | Android    |
| -------------- | ---------------------------- | -------------- | ---------- |
| 工作区         | 浏览器本地存储（FSA / OPFS） | 本机目录最完整 | 沙箱 / SAF |
| 同步与复制链接 | 有                           | 有             | 有         |
| 图片轻处理     | 有                           | 有             | 有         |
| 局域网临时共享 | 无                           | 未做           | 无         |

## 七、安全

- Token 仅存本机；泄露请到平台吊销并重建。
- 私有仓同步后，复制出的链接不一定能给外人打开——这是仓库策略，不是 Pixuli「少点了发布」。

---

## 八、常见问题

**添加后远端没有？**  
添加只写本机。点同步才会推远端。

**复制链接提示仅本地？**  
先同步；有连接引导时按提示去连接或去同步。

**刷新后 Web 工作区打不开？**  
浏览器可能丢了文件夹授权，按提示重新连接文件夹（配置一般还在）。

**旧版「图片工具 / 压缩页」呢？**  
已并入资源库的处理弹窗；设置里不再有图片工具开关。
