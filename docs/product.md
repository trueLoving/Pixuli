# Pixuli 产品说明

> 产品底线与硬规则（精简 SSOT）。怎么用见 [guide.md](./guide.md)；为什么见
> [DECISIONS.md](../DECISIONS.md)。

---

## 1. 定位

**本地优先的资源工作区**：本机文件夹是 SSOT；GitHub /
Gitee 为可选同步；外链靠复制链接。三端共用一份 `app`（Web PWA · Desktop Electron
· Mobile Capacitor Android）。**无官方 Server**，无用户向「发布」。

三条主线（并行，互不代替）：

| 主线     | 含义                                      | 现状                            |
| -------- | ----------------------------------------- | ------------------------------- |
| **保管** | 本机工作区 + 显式同步                     | 主路径已通                      |
| **处理** | 按文件类型本机加工，结果写回库            | 图片：裁剪 / 转换；压缩写回待补 |
| **共享** | 复制远端链接；桌面局域网只读 HTTP（未做） | 复制链接已通                    |

北极星：**本机整理 → 同步公开仓 → 复制 raw 贴进 Markdown**（站点 / 博客配图）。

---

## 2. 用户只记三句

1. 改库 = 只动本机
2. 要远端一样 → 点同步
3. 要给人看 → 复制链接

同步 ≠ 外网可访问。公开仓 raw 通常可开；私有仓往往不能——由仓库策略决定，不是库内再点「发布」。

---

## 3. 硬规则

| 操作                      | 范围           | 自动同步？     |
| ------------------------- | -------------- | -------------- |
| 浏览 / 搜索 / 预览        | 本地           | 否             |
| 文件夹 CRUD、文件增删改移 | **仅本地**     | **否**         |
| 图片处理（裁剪 / 转换）   | **仅本地**产物 | **否**         |
| 同步 pull / push          | 本地 ↔ 远端   | 是（单独入口） |
| 复制链接                  | 只读展示 URL   | 否             |

- 「添加」≠ 上传到云；禁止「已同步到云」类误导文案。
- 删改确认写清「仅本机」；不同时勾选「删远端」。
- 同步态只读展示：**仅本地** / **已同步**。
- 不向用户暴露 index / binding / manifest 等实现词。
- 同步不锁库：同步中仍可浏览与整理。
- **类型决定操作**：图片有处理；无能力则隐藏，不放死按钮。

## 4. 信息架构（薄）

```text
工作区
  └── 当前文件夹（面包屑 + 子文件夹 + 本层文件）
连接（设置 · 同步向导）—— 活动栏同步
外链 —— 复制链接（无「发布」）
处理 —— 选中后的类型化动作（当前：图片）
```

活动栏：资源库 · 同步 · 设置。侧栏不再放独立压缩 / 转换页。

窄屏：抽屉侧栏 / sheet 详情；旅程与宽屏相同，只改编排。

---

## 5. 连接与外链

- 官方连接近期只保 **GitHub + Gitee**（PAT 向导即可闭环；OAuth / Drive 延后）。
- 复制链接三态：无连接 → 去连接；仅本地 → 去同步；已同步但私有 → 如实附注。
- Provider 有 `publicUrl` / `buildPublicUrl` 才谈公网链；无能力不假装。

---

## 6. 处理（演进）

| 类型       | 现在                 | 以后可加（按格）                 |
| ---------- | -------------------- | -------------------------------- |
| 图片       | 查看；裁剪；转换写回 | 压缩写回等预设                   |
| PDF / 视频 | 查看                 | 轻量本机能力；重处理优先 Desktop |
| Markdown   | 当普通文件           | 大纲 / 关系等                    |

结果一律进当前文件夹旁，标仅本机，不自动入队推送。

## 8. 明确不做 / 延后

**不做：** 官方 NestJS Server；用户向「发布」；恢复幻灯片 / 时间线 / 照片墙 /
3D 画廊；取消三端任一端；默认 Gitee 图片 Host 代理。

**延后：**
Drive、全员 OAuth、同步任务抽屉、网格·列表切换、回收站、AI 标签、桌面离线队列 / 自动更新、局域网临时共享、文档全英镜像。

进度以 [GitHub Issues](https://github.com/trueLoving/Pixuli/issues) 与根
[PLANS.md](../PLANS.md) 为准。
