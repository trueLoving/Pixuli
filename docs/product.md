# Pixuli 产品说明

> 产品底线与硬规则（精简 SSOT）。怎么用见 [guide.md](./guide.md)；为什么见
> [DECISIONS.md](../DECISIONS.md)。

## 1. 定位

**本地优先的资源工作区**：本机文件夹是 SSOT；GitHub /
Gitee 为可选同步；外链靠复制链接。三端共用一份 `app`（Web PWA · Desktop Electron
· Mobile Capacitor Android）。**无官方 Server**，无用户向「发布」。

三条主线（并行，互不代替）：

| 主线     | 含义                                   | 现状                              |
| -------- | -------------------------------------- | --------------------------------- |
| **保管** | 本机工作区 + 显式同步                  | 主路径已通                        |
| **处理** | 按文件类型本机加工，结果写回库         | 图片：裁剪 / 转换；压缩写回待补   |
| **共享** | 复制远端链接；桌面局域网只读 HTTP Host | 复制链接已通；Desktop LAN Host v1 |

北极星：**本机整理 → 同步公开仓 → 复制 raw 贴进 Markdown**（站点 / 博客配图）。

---

## 2. 用户只记三句

1. 改库 = 只动本机
2. 要远端一样 → 点同步
3. 要给人看 → 复制链接

同步 ≠ 外网可访问。公开仓 raw 通常可开；私有仓往往不能——由仓库策略决定，不是库内再点「发布」。

## 3. 硬规则

| 操作                      | 范围                | 自动同步？        |
| ------------------------- | ------------------- | ----------------- |
| 浏览 / 搜索 / 预览        | 本地                | 否                |
| 文件夹 CRUD、文件增删改移 | **仅本地**          | **否**            |
| 图片处理（裁剪 / 转换）   | **仅本地**产物      | **否**            |
| 同步 pull / push          | 本地 ↔ 远端        | 是（单独入口）    |
| 恢复同步检查点            | 整库 → 上次同步成功 | 设置 · 同步检查点 |
| 复制链接                  | 只读展示 URL        | 否                |

- 「添加」≠ 上传到云；禁止「已同步到云」类误导文案。
- 删改确认写清「仅本机」；不同时勾选「删远端」。
- 同步态只读展示：**仅本地** / **已同步**；命中本机忽略规则时提示 **不同步**。
- 设置 · 同步可配置忽略规则（本机）；已同步后再忽略不删远端。
- 不向用户暴露 index / binding / manifest 等实现词。
- 同步不锁库：同步中仍可浏览与整理。
- **本地检查点**：同步成功后仅本机保留最近一次；设置中恢复。推送时若远端已变，须先拉取再推。
- **类型决定操作**：图片有处理；无能力则隐藏，不放死按钮。

## 4. 信息架构（薄）

```text
顶栏工作区标签（规划中）
  └── 当前活动工作区
        └── 当前文件夹（面包屑 + 子文件夹 + 本层文件）
连接（该工作区内 · 设置 · 同步向导）—— 活动栏同步
外链 —— 复制链接（无「发布」）
处理 —— 选中后的类型化动作（当前：图片）
```

活动栏：资源库 · 同步 · 设置。侧栏不再放独立压缩 / 转换页。

窄屏：抽屉侧栏 / sheet 详情；旅程与宽屏相同，只改编排。

### 4.1 多工作区（规划 · 页签会话）

**目标：** 顶栏采用类似浏览器标签的交互；**一个标签 = 一个完整工作区会话**。

| 交互     | 含义                                                          |
| -------- | ------------------------------------------------------------- |
| 新建标签 | 重新走「打开 / 创建工作区」流程（选本机根等），得到一个新会话 |
| 切换标签 | 切换活动工作区；库视图、远端、共享状态随会话切换              |
| 关闭标签 | 卸下会话（默认不删磁盘上的库文件）                            |

**隔离边界（每个工作区彼此独立）：**

- 本机根与库内容（文件 / 文件夹 / 元数据 / 检查点等）
- 远端连接（GitHub / Gitee 等绑定与同步态）
- 局域网共享（若开启 Host，只服务该工作区；同一时刻以活动标签为准）
- 该会话内的浏览记忆（当前文件夹、选中等）

**全局可共享：** 语言、主题、应用壳层等与「哪一个库」无关的偏好。

**现状：**
应用层仍为**同一时间一个本地根**（更换文件夹 = 替换而非并行）。多页签为已拍板的产品方向，实现前不得用「换夹」冒充多工作区。

## 5. 连接与外链

- 官方连接近期只保 **GitHub + Gitee**（PAT 向导即可闭环；OAuth / Drive 延后）。
- 复制链接三态：无连接 → 去连接；仅本地 → 去同步；已同步但私有 → 如实附注。
- Provider 有 `publicUrl` / `buildPublicUrl` 才谈公网链；无能力不假装。
- **局域网共享（Desktop Host
  v1）**：设置 · 访问开启只读 HTTP；同 Wi‑Fi 浏览器浏览的是
  **Vault 库视图**（与 Desktop 文件夹/展示名一致，非裸磁盘树）；可**仅下载**转移包，或点「在 Pixuli 中导入」经
  `pixuli://`
  深链唤起本机 App。导入入口：库工具栏、设置 · 局域网共享、拖放 zip；策略支持跳过同名 / 覆盖同名 /
  **替换整个目标文件夹（含子目录）**；支持
  **一键整库同步到手机**（PC 生成同步二维码 / 访客页一键同步 → 深链导入并以替换根目录策略写入，需在 App 内确认）。默认当前文件夹并记住上次目标与策略。开共享设备为会话蓝本；近场整库覆盖 ≠
  Git 双向同步。可写 / 移动端 Host 延后。

## 8. 明确不做 / 延后

**不做：** 官方 NestJS Server；用户向「发布」；恢复幻灯片 / 时间线 / 照片墙 /
3D 画廊；取消三端任一端；默认 Gitee 图片 Host 代理。

**延后：**
Drive、全员 OAuth、同步任务抽屉、网格·列表切换、回收站、AI 标签、桌面离线队列 / 自动更新、局域网可写/移动端 Host、文档全英镜像。

进度以 [GitHub Issues](https://github.com/trueLoving/Pixuli/issues) 与根
[PLANS.md](../PLANS.md) 为准。
