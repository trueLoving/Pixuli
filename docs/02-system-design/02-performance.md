# 性能边界与列表策略

- **文档版本**：1.0
- **日期**：2026-08-25
- **关联**：REF-603 · [PLANS.md](../../PLANS.md)

> 本地工作区下列表以**本地索引**为准；远端同步增量，不在首屏拉全库 blob。

---

## 一、已落地

| 场景       | 策略                      | 位置                                                         |
| ---------- | ------------------------- | ------------------------------------------------------------ |
| 文件表滚动 | 行虚拟窗口（非整表 DOM）  | `virtualWindow.ts` + `AssetLibrary`（行高 44，`overscan` 8） |
| 图片缩略   | 原 URL + `loading="lazy"` | `AssetThumb`（仅窗口内挂载）                                 |
| 视频缩略   | 近片头帧 → JPEG           | `assetThumbnail.captureVideoThumbnail`                       |
| PDF 缩略   | pdf.js 首页 → JPEG        | `assetThumbnail.capturePdfThumbnail`                         |
| 缩略压力   | 内存 LRU ≤ 120；并发 ≤ 3  | `assetThumbnail.ts`                                          |

**SLA（开发机、本地库、冷启动）**：文件表可交互 \< 3s（不含全量缩略完成）。

| 规模       | 预期                                      |
| ---------- | ----------------------------------------- |
| ≤ 500      | 虚拟窗口足够                              |
| 500～5 000 | 依赖窗口 + 缩略限流                       |
| \> 5 000   | 需持久索引/分页或强制缩小范围（**未做**） |

## 三、Mobile / WebView

- 视频取帧失败 → 类型图标；Android WebView 对 blob 差异大。
- PDF worker 须可解析（Vite `?url` / `import.meta.url`）。
- 勿在主线程同步解码大 PDF。
