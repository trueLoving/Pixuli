> 本地工作区模式下，列表以**本地索引**为准；远端同步是增量，不在首屏一次性拉全库blob。本文记录**已落地数字**与**待补策略**，避免大数据量时内存与主线程卡顿。

---

## 一、已落地（H 批次部分）

| 场景              | 策略                             | 实现位置                               | 备注                                           |
| ----------------- | -------------------------------- | -------------------------------------- | ---------------------------------------------- |
| 文件表首屏 / 滚动 | **行虚拟窗口**（非整表 DOM）     | `virtualWindow.ts` + `AssetLibrary`    | 行高 `LIBRARY_ROW_HEIGHT = 44`；`overscan = 8` |
| 图片缩略          | 原 URL + `loading="lazy"`        | `AssetThumb`                           | 仅虚拟窗口内行挂载                             |
| 视频缩略          | 取靠近片头帧 → JPEG data URL     | `assetThumbnail.captureVideoThumbnail` | 失败回退类型图标；跨域 canvas 污染则失败       |
| PDF 缩略          | pdf.js 首页 → JPEG data URL      | `assetThumbnail.capturePdfThumbnail`   | 动态 `import('pdfjs-dist')`；worker 随包       |
| 缩略生成压力      | 内存 LRU ≤ **120**；并发 ≤ **3** | `assetThumbnail.ts`                    | 与虚拟窗口叠加，避免同时解上千文件             |

### 经验阈值（本地 / Web，可再测）

| 规模       | 预期                                                | 产品提示                       |
| ---------- | --------------------------------------------------- | ------------------------------ |
| ≤ 500      | 虚拟窗口足够，首屏可接受                            | 无                             |
| 500～5 000 | 依赖虚拟窗口 + 缩略并发限制                         | 可选：状态栏「缩略图按需生成」 |
| \> 5 000   | 需元数据索引 / 分页或文件夹强制缩小范围（**未做**） | 提示缩小目录（待做）           |

SLA（开发机、本地工作区、冷启动）：**首屏文件表可交互 \<
3s**（不含全量缩略生成完成）。缩略为渐进增强。

## 三、Mobile / WebView 注意

- 视频取帧依赖 `<video>` + canvas；部分 Android
  WebView 对本地 blob 支持差异大 → 失败即图标。
- PDF 依赖 pdf.js worker；Capacitor 打包需确保 worker URL 可解析（Vite `?url` /
  `new URL(..., import.meta.url)`）。
- 勿在主线程同步解码大 PDF；当前已异步 + 并发上限。
