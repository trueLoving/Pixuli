# 键盘快捷键场景清单

> 产品约定：**打开弹层 = 切到新场景**；场景有私有快捷键；`Esc`
> 退出回到上一场景。  
> 范围：Web /
> Desktop 键盘操作。移动端以手势为主，**不在本清单实现范围内**（窄屏抽屉若出现在桌面宽高临界，另注）。

相关实现入口：`app/src/hooks/keyboardShortcuts.ts`、`app/src/features/library/libraryShortcutGate.ts`、`app/src/ui/utils/keyboardShortcuts.ts`。

---

## 1. 主入口与「未开库」

**键盘体系的主入口是 `library`（已打开本地工作区后的资源库）**，不是欢迎页。

| 状态                                                    | 是否当作快捷键主场景 | 说明                                                                                                           |
| ------------------------------------------------------- | -------------------- | -------------------------------------------------------------------------------------------------------------- |
| 已开库 → `library`                                      | **是（唯一基底）**   | ↑↓ / E / 搜索 / 面板切换等全部挂在这里；弹层从这里压栈、Esc 回到这里                                           |
| 未开库 → 欢迎 / 选夹 / 迁移（`WorkspaceWelcomeScreen`） | **否**               | 这是一次性 onboarding，不是日常操作环。↑↓ 换选、E、搜索等**没有对象**，不必做成与 `library` 对等的第二套主场景 |

建议策略：

1. **工程与产品默认：专注 `library` + 其弹层场景。**
   场景栈、帮助文案、优先级都以库为中心。
2. **欢迎页不扩库级快捷键。**
   避免用户在无库时按 E/↑↓ 产生空操作或误开无意义弹层。
3. **欢迎页最多保留「壳层最小集」（可选、P3）**：例如 Enter 触发主 CTA（选择文件夹）、Ctrl/⌘+/ 打开设置·同步、F5 帮助。这属于 onboarding 便利，**不**进入日常场景栈设计的主路径。
4. 开库成功进入 `library` 后，再启用完整库快捷键。

因此：不是「有没有工作区都要一套完整快捷键」，而是
**「有库才进入键盘主循环」**。

## 2. 从 `library` 出发：键位设计（审阅稿）

> 本节只描述 **人在资源库场景时** 能按什么键。  
> 分两类：**留在库内的操作**，以及 **进入其它场景的入口键**。  
> 标记：✅ 已实现 · 📝 设计保留/待补 · — 暂不设快捷键（鼠标/菜单进入）

### 2.1 设计原则

1. **字母单键**（无修饰）：只做「对当前选中项」的高频动作（编辑、分享），避免与输入抢键。
2. **修饰键组合**：打开壳层/工具类场景（搜索、设置、帮助、面板）。
3. **方向 / Enter**：库内导航与打开预览；**不**在库场景用方向键打开设置类弹层。
4. **未选中文件时**：依赖选中的入口键（E / S /
   Enter）应 no-op，不报错、不乱开空弹层。
5. **多选**：`M` 进入；Esc 退出并清空勾选。进入后 E / Enter / S
   no-op（批量走工具栏）；↑↓ 只移动焦点；Space 切换焦点行勾选。
6. **进入场景后**：下列「入口键」在弹层内默认失效，直到 Esc 回库（帮助的 F5 可自洽开关）。

### 2.2 留在 `library` 的操作（不压栈）

| 键        | 动作                                      | 状态 | 备注                                                   |
| --------- | ----------------------------------------- | ---- | ------------------------------------------------------ |
| ↑ / ↓     | 上一项 / 下一项（含文件夹行与 `..`）      | ✅   | 单选：换选。多选模式：只移动焦点，不改勾选             |
| M         | 进入多选模式                              | ✅   | 已在多选时 no-op；退出用 Esc                           |
| Space     | 多选模式下切换当前焦点行勾选              | ✅   | 仅 `multiSelectMode`；与 ↑↓ 焦点配合                   |
| Enter     | 打开预览 → 进入 `preview`                 | ✅   | 见入口表；对文件夹可为进入文件夹（若已有）；多选 no-op |
| Ctrl/⌘+B  | 显隐文件夹大纲（宽屏折叠 / 窄屏 overlay） | ✅   | 窄屏打开 overlay 时可视作进入 `folder-overlay`         |
| Ctrl/⌘+I  | 显隐 Inspector                            | ✅   | 不压栈，仍属库场景 UI                                  |
| Ctrl/⌘+⇧K | 清除当前搜索查询                          | ✅   | 留在库；有查询时才有体感                               |
| Esc       | 关库内瞬态；多选模式则退出多选            | ✅   | 先关 `context-menu`；再退出多选并清空勾选              |

### 2.3 从 `library` 进入其它场景（入口键）

| 目标场景                    | 建议入口键               | 前置条件               | 状态        | 说明                                                                                                 |
| --------------------------- | ------------------------ | ---------------------- | ----------- | ---------------------------------------------------------------------------------------------------- |

| `folder-overlay`            | Ctrl/⌘+B（窄屏）         | 窄布局                 | ✅          | 宽屏仅为折叠，不算进场景                                                                             |
| `workspace`                 | —                        | —                      | —           | 从设置进即可                                                                                         |

### 2.4 建议定稿的「库场景入口键一张表」（给人看的）

仅列 **推荐对外承诺** 的键（帮助浮层 / 文档可直接用）：

```text
导航（留在库）
  ↑ ↓           选择上一项 / 下一项（多选模式：只移动焦点）
  M             进入多选模式
  Space         多选模式：切换焦点行勾选
  Ctrl/⌘ + B    文件夹大纲
  Ctrl/⌘ + I    Inspector

打开场景
  Enter         预览选中文件（多选 no-op）
  E             编辑选中文件（多选 no-op）
  ⌘K / Ctrl+K   搜索
  Ctrl/⌘ + /    设置
  F5            快捷键帮助（打开后 ↑↓ 滚动，Esc 回库）

库内动作（不换场景）
  S             复制选中文件分享链接（多选 no-op）
  Ctrl/⌘ + ⇧K   清除搜索

退出场景
  Esc           关闭当前弹层 / 退出多选 / 回到库
```

**明确不进对外承诺（除非以后单开需求）：**
同步、上传、处理、批量编辑/移动的专用快捷键。

### 2.5 与现状差异（仅入口相关）

| 项                        | 现状                                                | 设计稿                                        |
| ------------------------- | --------------------------------------------------- | --------------------------------------------- |

## 3. 模型

```text
[欢迎 / 未开库]  ··· 可选最小壳层键；不是主循环
        │ 选夹 / 开库成功
        ▼
[库场景 library]  ← 键盘主入口 / 基底
   │  快捷键进入（E / ⌘K / Ctrl+/ / F5 / …）
   ▼
[弹层场景]  ← 仅使用本场景快捷键；库场景快捷键挂起
   │  Esc（或场景完成关闭）
   ▼
[库场景]    ← 恢复库快捷键
```

规则：

1. **同一时刻只有栈顶场景消费方向键 / 字母快捷键**（`Esc`、必要时 `F5`
   可跨层约定）。
2. **焦点在可编辑控件内**（input / textarea /
   contenteditable）时，场景字母/方向快捷键默认不抢（表单输入优先）。
3. **禁止穿透**：弹层打开时，背后库列表不得被 ↑↓ 换选。
4. **嵌套**：裁剪可叠在上传/处理之上 → 场景栈深度 ≥ 2；只关栈顶。
5. **未开库不注册库级键**（↑↓ / E / S / ⌘K 等）；与「主入口 = library」一致。

## 5. 按层归类

### 5.1 基底场景（常驻，开库后）

- `library`：**唯一**键盘主循环基底。库级与（在库内时的）壳层进入键挂在这里。

### 5.2 一级弹层场景（从库直接进入）

- `search` · `preview` · `edit` · `settings` · `keyboard-help` ·
  `sync-direction` · `upload` · `convert` · `batch-edit` · `batch-move` ·
  `workspace` · `folder-overlay`

### 5.3 嵌套 / 子场景

- `crop` ← `upload` 或 `convert`
- `connection-wizard` ← `settings`
- `context-menu` ← `library`（瞬态，不改「当前文件」语义，但应挡住库 ↑↓）

### 5.4 开库前（非主循环）

- `welcome`：不进入场景栈主设计；开库后切换为 `library`。

### 5.5 跨场景壳层键（约定）

| 键             | 库场景                             | 弹层场景                           | 未开库欢迎         |
| -------------- | ---------------------------------- | ---------------------------------- | ------------------ |
| Esc            | 关顶层瞬态（菜单/overlay）或无操作 | **退出栈顶场景**                   | 无或仅关误开弹层   |
| F5             | 打开帮助                           | 帮助内可再按关闭；其它弹层默认不抢 | 可选打开帮助（P3） |
| Ctrl/⌘+/       | 打开设置                           | 默认不响应                         | 可选打开设置（P3） |
| ⌘K · E · ↑↓ 等 | 库导航 / 进子场景                  | **默认不响应**                     | **不注册**         |

## 6. 与现状代码的差距（摘要）

| 已有                                                              | 缺口                                                                       |
| ----------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 库级快捷键多在 `AssetLibrary` 挂载时注册（无库时 naturally 较弱） | 应用级仍有 Ctrl+/、F5 等，欢迎页也可能触发——可接受，但勿再扩库级键到欢迎页 |

## 7. 建议落地顺序

1. **审阅并冻结 §2.4 库场景入口键表**。
2. **文档与命名**：本清单为准；**主入口锁定
   `library`**，欢迎页不并行一套主场景。
3. **薄场景栈**：`push/pop` + 栈顶消费按键；替换散落的「仅 suspend 库键」。
4. **P0**：`settings` 场景内键盘（侧栏/选项 ↑↓+Enter）+ 确认 Esc 回库。
5. **P1**：`search` 历史巡航、`sync-direction` 选择确认。（`edit` 场景键已落地）
6. **P2**：批量 / 上传 / 处理 / 连接向导子场景。
7. **P3（可选）**：`welcome` 最小壳层键。
8. **帮助文案**：按 §2.4 三组展示（可后置）。
