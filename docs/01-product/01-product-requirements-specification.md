## 三、项目概述

### 3.1 背景

Pixuli 源于两类需求：

1. **实际需求**：博客与网站运营中统一的图片存储、压缩与批量处理需求。
2. **技术实践**：在已有 Vue3 图片管理应用经验基础上，使用 React 技术栈重新实现，并扩展至多平台（Web、桌面、移动端）。

### 3.2 产品定位

Pixuli 是一款**本地优先的资源工作区客户端**（三端共用 `app`）：

- **Web**：Vite + React，支持 PWA
- **Desktop**：Electron，与 Web 同一套 UI
- **Mobile**：Capacitor Android（Expo RN 已归档）

**核心价值**：

- 管理 **多种资源**（图片、PDF、视频等），本地工作区为 SSOT
- 用 **连接器** 对接 GitHub、Gitee、OneDrive、Google Cloud 等；官方不提供 NestJS
  Server
- **控制对外访问**：本地始终可用；远程按云能力发布或明确提示不支持
- 阶段一已交付路径：图片 + GitHub/Gitee 图床（仍保留）

### 3.3 目标用户

- 个人博客 / 静态站：稳定公网直链（Git 图床）
- 内容与知识工作者：图片、PDF、视频同库管理，按需同步到个人云
- 需要把部分资源分享到外网、其余保持私有的创作者与开发者
