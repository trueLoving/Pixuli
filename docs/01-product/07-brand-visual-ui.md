## 一、从 Logo 抽出的色板

取样自 `public/icon.png`（忽略纯黑底）。UI 用语义 token，不要在组件里写死
`#3b82f6`。

| Token               | 建议值    | Logo 来源                       | 用途                                               |
| ------------------- | --------- | ------------------------------- | -------------------------------------------------- |
| `--pix-violet`      | `#7C6CF0` | 主体中位紫 `#7070f0`～`#8070f0` | 品牌主色：活动栏选中、主按钮、焦点环               |
| `--pix-violet-deep` | `#5B4FE0` | 暗面 `#6060e0` / `#5060f0`      | 主按钮 hover、侧栏 active 条                       |
| `--pix-violet-soft` | `#EDE9FE` | 浅薰衣草（右面上沿）            | 选中底、chip、设置当前项                           |
| `--pix-cyan`        | `#5EE1F7` | 顶面光柱 / 浮点                 | **强调 / 活性**：同步中、在线、公开、进度          |
| `--pix-cyan-deep`   | `#22D3EE` | 青偏实                          | 链接、同步徽章「进行中」                           |
| `--pix-lilac`       | `#C4B5FD` | 亮面 `#a080f0`                  | 次要图标、empty 插画描边                           |
| `--pix-warm`        | `#FBBF24` | 缩略图里的「太阳」              | **仅点缀**：成功微标、类型「图片」小点，禁止大面积 |
| `--pix-ink`         | `#1E1B4B` | 深紫近黑（非纯黑）              | 深色模式正文 / 欢迎页可选底                        |
| `--pix-surface`     | `#FAF8FF` | 浅紫白                          | 页面底（浅色模式），替代纯 `#fff` 可极淡           |
| `--pix-danger`      | `#E11D48` | （功能色，Logo 无）             | 删除、冲突；不要用紫表示错误                       |

**角色分工（重要）**：

- **紫** = 品牌与导航（我是谁、我在哪）
- **青** = 系统在动 / 对外连通（同步、在线、发布成功）
- **暖黄** = 媒体内容的一丁点高光，不当主色
- **灰** = 中性文字与边框，保持现有 `#111827` / `#6b7280` / `#e5e7eb` 即可

浅色模式仍以白/浅灰为画布，紫青只做强调，避免整页做成 Logo 那样的黑底霓虹（图标可以，工作区阅读不行）。深色模式可用
`--pix-ink` 底 + 青作焦点，与 Logo 更近，但对比度须过 WCAG AA。

## 二、与现状的差距

| 位置       | 现在                                         | 建议                                                              |
| ---------- | -------------------------------------------- | ----------------------------------------------------------------- |
| 全局主色   | `#3b82f6` / `#2563eb`（蓝）                  | `--pix-violet` / `--pix-violet-deep`                              |
| Welcome    | 底 `#eef2ff`（靛蓝）、图标 `#2563eb`         | 淡紫底 `#F5F3FF`→`#EEF2FF`；品牌区用 Logo 或紫立方，不要蓝 Lucide |
| Empty      | 灰色 Lucide `Image` / `SearchX` `opacity-50` | 像素立方空态（见 §四），主 CTA 用紫                               |
| Loading    | 蓝 spinner                                   | 青像素点上升 / 顶面光柱循环（见 §五）                             |
| 同步中     | 蓝 `RefreshCw` spin                          | **青色** + 可选光点，与「品牌紫按钮」区分                         |
| 选中/焦点  | 蓝 ring、蓝条                                | 紫 ring；同步/在线态用青点                                        |
| 上传主按钮 | 蓝描边                                       | 紫实心或紫描边                                                    |

硬编码散落在 `@pixuli/ui` 的
`ImageBrowser`、`Sidebar`、`ImageActionMenu`、`EmptyState`
等，迁移时应改为 token，避免再写 Tailwind `blue-*`。

## 三、语义色 → 产品状态

对齐阶段二：本地 / 远程 / 访问档位。

| 状态               | 色                                         | UI                               |
| ------------------ | ------------------------------------------ | -------------------------------- |
| 本地 only、未发布  | 中性灰 + 锁图标                            | 不抢色                           |
| 已同步到远端       | 小青点                                     | 树节点、卡片角标                 |
| 同步中 / pull·push | **青** + 动效                              | 活动栏徽章、全屏 loading 文案旁  |
| 冲突 / 失败        | `--pix-danger`                             | 角标 + `ContentFeedback`，不用紫 |
| 公开 / 可外链      | 青地球或青描边 chip                        | 访问面板「公开」档               |
| 仅链接             | 紫链图标                                   | 比公开更「品牌」、比青更静       |
| 云不支持该档       | 灰禁用 + 提示条（琥珀/中性，非红除非危险） | F-ACCESS-03                      |
| 活动栏当前项       | 紫底/紫条                                  | 不要青，避免和同步抢             |

## 四、Empty 状态

Logo 右面是「有图的格子」、左面是「有字的目录」、顶面是「有光的通道」。空态应是
**同一立方，但格子空、目录空、顶面无光**——用户一眼知道「这是 Pixuli 的库，只是还没内容」，而不是通用灰色图片图标。

### 4.1 插画（三端同一套 SVG/PNG，放 `brand/` 或 `@pixuli/ui` empty 资源）

| 场景                        | 画面                                                      | 文案方向（i18n）                                 |
| --------------------------- | --------------------------------------------------------- | ------------------------------------------------ |
| **资源库空**                | 像素立方，右面 2×3 空框（白边无风景），顶面无青光、无浮点 | 「工作区还没有资源」；CTA：上传 / 从远端拉取     |
| **筛选无结果**              | 立方在，右面格子打淡 + 一个放大镜像素标                   | 「没有匹配的资源」；CTA：清除筛选                |
| **未打开工作区**            | 完整 Logo（可缩小）或空立方 + 虚线底座                    | 欢迎页已有流程；图标改用 Logo，去掉蓝 FolderTree |
| **无连接**                  | 立方顶面暗，青光熄灭                                      | 「尚未连接云存储」；CTA：添加连接                |
| **无已发布**                | 立方在，顶面关，一把小锁像素                              | 「没有对外公开的资源」；CTA：在资源上设置访问    |
| **某类型空**（仅 PDF/视频） | 右面格子空，左面目录亮（或反过来）                        | 「还没有 PDF / 视频」；保留「查看全部」          |

风格约束：

- **像素 / 等距**，圆角立方，与 Logo 同一透视，不要改成扁平插画或 3D 写实。
- 浅色模式：浅紫灰立方（`#C4B5FD` 描边，`#EDE9FE` 面），**不要**黑底霓虹空态。
- 深色模式：可用接近 Logo 的紫立方 + 弱青，但背景仍是 `--pix-ink` 而非纯黑刺眼。
- 尊重 `prefers-reduced-motion`：空态默认静止。

### 4.2 结构（组件）

```text
[插画 96–128px]
标题
说明（一行，本地 vs 远程差异用独立 i18n）
[主 CTA 紫]  [次 CTA 描边]
```

`ImageLibraryEmpty` 不要只用 Lucide；Welcome 品牌色不要 `#2563eb`。主按钮走
`--pix-violet`，次按钮中性描边。

## 五、Loading 状态

Logo 顶面青光 + 向上浮点 = 天然「数据在进出库」。Loading 用
**青像素运动**，不要蓝圈 spinner 当品牌。

| 场景                             | 建议                                                                                            |
| -------------------------------- | ----------------------------------------------------------------------------------------------- |
| **全屏**（打开工作区、首次扫库） | 缩小 Logo 或空立方，顶面青光呼吸；3～5 个 4px 青方块向上循环淡出；文案在下（「正在加载资源…」） |
| **Banner / 局部**                | 青细进度条或青点脉冲，不要整页挡操作（除非必须）                                                |
| **同步中**                       | 活动栏同步图标 **青色** + 慢旋或光点；徽章「同步中」用青底白字                                  |
| **上传队列**                     | 青进度；完成瞬间可闪一下暖黄点（媒体入库），随即复原                                            |
| **按钮 loading**                 | 按钮内青点，背景仍紫（紫=动作归属，青=进行中）                                                  |
| **骨架屏**（网格）               | 卡片骨架淡紫 `#EDE9FE` shimmer，禁止蓝灰 Tailwind 默认                                          |

动效：

- 周期约 1.2s，缓入缓出，不要线性狂转。
- `prefers-reduced-motion`：停浮点，只留静态青点 + 文案。
- 全屏遮罩浅色模式用白 90% + blur（可保留）；深色用 `--pix-ink`
  90%，spinner/光柱用青。

## 六、其它与 Logo 对齐的 UI

| 元素                       | 建议                                                                            |
| -------------------------- | ------------------------------------------------------------------------------- |
| **欢迎页**                 | 背景极淡紫渐变；中央用 Logo（或空立方）；主按钮紫；不要蓝图标                   |
| **活动栏**                 | 选中：紫指示条；同步 busy：青；设置：中性                                       |
| **资源卡片**               | 选中描边紫；已发布角标青；冲突红                                                |
| **访问面板**               | 「公开」选项旁青点；「仅本地」灰锁；不支持项灰 + 提示条                         |
| **焦点环**                 | `2px solid --pix-violet`（键盘可达，REF-601）                                   |
| **滚动条 / 选区**          | 可选淡紫，勿青（青留给「系统在动」）                                            |
| **Favicon / PWA / 启动屏** | 已用同一 `brand/source`；启动屏底可用深紫或浅紫，中心 Logo，避免再套蓝 Material |

**不要**：

- 把界面做成全像素风操作系统（可读性优先，正文仍用系统/现有无衬线）。
- 大面积青底白字（对比与「医疗/通知」感）；青只做 8～16px 级强调。
- 用紫表示删除/错误。
- 浅色模式整页黑底模仿 Logo。
