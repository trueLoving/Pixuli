- **文档版本**：2.0
- **日期**：2026-08-13
- **读者**：产品、设计、前端（Web / Desktop / Capacitor Android）
- **需求 SSOT**：[01-product-requirements-specification.md](./01-product-requirements-specification.md)
  v2.3（§2.1a / §5.8a）
- **阶段二 IA 细节**：[06-asset-library-ui.md](./06-asset-library-ui.md)
- **交互规范（壳层/手势）**：[04-three-platform-interaction-spec.md](./04-three-platform-interaction-spec.md)（REF-601）
- **工程 SSOT**：[06-apps-pixuli-engineering.md](../02-system-design/06-apps-pixuli-engineering.md)
- **品牌色 / empty / loading**：[07-brand-visual-ui.md](./07-brand-visual-ui.md)

> **现行需求一句话**：本地优先的资源工作区；管理 **图片 / PDF / 视频**
> 等；用连接器对接 **GitHub、Gitee、OneDrive、Google Cloud**
> 等；**本地始终可访问**；**远程对外访问**按云能力配置，不支持则
> **UI 禁用并提示**。
>
> **三端底线**：Web / Desktop / Mobile 共用 `apps/pixuli` +
> `@pixuli/ui`。流程一致，壳层适配；不为 Mobile 另开一套 UI。
>
> 本文是 **对照现行需求的 UI 排期与建议**。连接器能力位、发布抽屉线框以
> [06](./06-asset-library-ui.md) 为准；断点/手势以 REF-601 为准。

## 一、需求 → UI 必须讲清的四件事

| PRS          | 用户要完成的事                    | UI 必须出现的面                                     |
| ------------ | --------------------------------- | --------------------------------------------------- |
| F-ASSET-\*   | 同库管理图 / PDF / 视频           | **资源库**（类型筛选 + 按类型预览），不是「仅照片」 |
| F-CONN-\*    | 连上不同云，本地 SSOT + 可选同步  | **连接**（能力摘要 + 健康状态），不是设置里一张表   |
| F-ACCESS-\*  | 控制对外访问：本地私有 / 远程发布 | **访问/发布**；本地与远程分列                       |
| F-ACCESS-03  | 云不支持某档访问                  | **禁用 + 原因 + 替代**，禁止静默或假成功            |
| 阶段一不回退 | 现有 GitHub/Gitee 图床仍可用      | 新 IA 先用 GitHub/Gitee 填满，再加 OneDrive / GCS   |

原则（叠在 REF-601 上）：

| 原则                    | 落地                                             |
| ----------------------- | ------------------------------------------------ |
| **流程一致 / 壳层适配** | 三端步骤相同；窄屏只改编排                       |
| **本地工作区优先**      | 浏览默认读本地；远程是柜子 + 发布通道            |
| **连接 ≠ 发布**         | 同步副本 ≠ 外网能打开                            |
| **降级显式**            | 端能力、云能力、类型不适用的工具，一律禁用并说明 |
| **可发现性**            | 上传、同步、访问控制、连接、工具有固定槽位       |

刻意不做：独立 RN
UI；恢复幻灯片/时间线/照片墙；为每种云单独做一套浏览界面；在 UI 里做云厂商控制台级 IAM。

## 二、现状对照现行需求

核对日：2026-08-13（工作区壳：欢迎页 + 活动栏 + 文件夹树 + `ImageBrowser`
banner）。

| 现行需求              | 实现现状                               | UI 差距                                 |
| --------------------- | -------------------------------------- | --------------------------------------- |
| 图片 / PDF / 视频同库 | 几乎仅图片网格；无 PDF/视频类型面      | 类型筛选、非图预览、工具对 PDF 禁用提示 |
| 多云连接器            | 仅 GitHub/Gitee，埋在设置「同步」表    | 一级 **连接**；卡片展示能力位           |
| 本地 + 远程           | 本地工作区 + pull/push 弹窗已有        | 缺同步徽章/结果；多连接时无「同步到哪」 |
| 按资源控制对外访问    | 复制 local/remote URL；无资源级策略    | **访问面板**：本地私有 vs 远程档位      |
| 云不支持则提示        | 无能力位 UI                            | 不支持的档位禁用 + 说明 + 替代          |
| 三端同一壳            | 工作区 IDE vs 旧侧栏两套；窄屏硬套桌面 | 统一主壳；`<768` 底栏 + sheet           |
| 工具 / AI             | 压缩转换隐藏；AI 仅 Desktop            | 固定槽位；无能力端显式禁用              |

阶段一仍可用：打开工作区 → 浏览图片 → 同步 Gitee/GitHub
→ 复制远端链接。阶段二是在这上面长出来，不是另起一个 App。

## 三、建议信息架构（三端共用）

宽屏：活动栏 + 资源树 + 主视图。窄屏：底栏 + sheet / 全屏页。详细线框见
[06 §三](./06-asset-library-ui.md)。

### 3.1 一级导航

建议固定槽位（宽屏活动栏 / 窄屏底栏，**≤5**）：

| 槽位 | 名称       | 对应需求          | 现状                                            |
| ---- | ---------- | ----------------- | ----------------------------------------------- |
| 1    | **资源库** | F-ASSET           | 现「照片」，先改名与类型筛选                    |
| 2    | **连接**   | F-CONN            | 从设置升格；无连接时空态 CTA                    |
| 3    | **访问**   | F-ACCESS          | 可先做资源库 banner「访问」+ 详情分区，再升一级 |
| 4    | **工具**   | 压缩/转换等       | 现隐藏，需恢复；非图片禁用                      |
| 5    | **设置**   | 工作区/语言/日志… | 已有弹窗；窄屏改全屏                            |

同步不要再占一个与「连接」重复的一级图标：放到资源库 **同步徽章**，点击仍选 pull
/ push；多连接时加「目标连接」。

窄屏底栏若只能 4 项：资源库 | 连接 | 访问 | 设置；工具进资源「更多」或访问页次级。树用 sheet，不要左侧常驻。

### 3.2 资源库主视图（F-ASSET）

Banner（宽屏一行 / 窄屏两行，搜索与操作同行——已部分落地）：

```text
[范围：图片|视频|PDF|全部]  [搜索+筛选]  [上传]  [视图]  [同步●]  [访问]
```

| 建议     | 说明                                                                   |
| -------- | ---------------------------------------------------------------------- |
| 类型范围 | 默认图片；一键切视频 / PDF / 全部（F-ASSET-01）                        |
| 预览     | 图：现预览层；视频：播放或占位；PDF：内嵌或系统打开（F-ASSET-02）      |
| 角标     | **本地可见性** + **同步态** +（若已发布）**远程档位**                  |
| 多选底栏 | 下载 / 同步到… / 访问… / 删除；压缩仅图片，否则禁用+提示（F-ASSET-03） |
| 中屏密度 | 搜索可收为图标，避免与上传、访问抢宽                                   |

上传按 MIME 分流：图走现确认流；PDF/视频走简表+预览；不支持类型仍可入库为「其他文件」。

### 3.3 连接（F-CONN）

从设置表格改为 **连接页**（列表 + 添加向导）。每张卡片必须能读懂：

- 服务与位置（如 Gitee `owner/repo`、OneDrive 文件夹）
- **能力**：同步 / 公开 URL / 分享链接 / ACL / 大文件流（来自 manifest，禁止按
  `pluginId` 写死文案）
- **健康**：待推送、冲突、上次同步
- 操作：设为默认同步目标、同步、编辑、断开

向导三步：选服务 → 授权与位置 → 用途（仅备份同步 / 默认同步 /
**允许作为发布通道**）。

GitHub/Gitee 先填满能力展示；OneDrive / Google Cloud 未落地时在画廊
**灰显 +「即将支持」**，不要假装已连接。

### 3.4 访问控制（F-ACCESS）— 本地与远程分列

这是相对旧「复制链接」最大的 UI 变化。同一面板两块，不可只做远程：

```text
访问设置 — {文件名}
  本地
    ● 本机工作区可浏览（始终开启，不可关）
    ○ 不对外发布
  远程 — 通道：[Gitee owner/repo ▾]
    ○ 不在该云公开          （始终可选）
    ○ 仅链接可见            （连接器无 shareLink → 禁用）
    ○ 公开 URL / 可热链     （无 publicUrl → 禁用）
    ○ 过期 / 口令           （无能力 → 禁用）

  [提示区] 若有禁用项：
    「当前连接不支持『公开 URL』。可：保持仅本地 /
     换用支持图床直链的连接（如公开 GitHub/Gitee 仓库）/
     使用该云官网分享（若有）。」

  [生成并复制链接]   [撤销远程访问]
```

规则：

1. **本地**：用户永远能看自己的资源；「仅本地」= 不发布，不是删文件。
2. **远程**：选项完全由该连接能力位驱动（F-ACCESS-02）。
3. **不支持**：禁用 + **标题/原因/替代**
   三要素提示（F-ACCESS-03），不能只 toast 或点击无反应。
4. 未同步到该通道却要发布 → 一次确认「先同步再发布」。
5. 复制公开链接时若尚未发布 → 引导进本面板，禁止静默抛出用户未确认的 raw URL。

「访问」总览（一级或资源库子模式）：已发布列表、通道、档位、到期、复制、撤销。

## 四、壳层与三端适配（仍是 P0）

阶段二 IA 若直接铺在当前桌面 IDE 上，Mobile 会不可用。壳层建议不变，槽位按 §3.1 改名。

### 4.1 统一主壳

工作区模式 =
**唯一主壳**（Web/Desktop/Android）。旧侧栏仅无工作区平台降级并规划下线。

### 4.2 窄屏 `<768px`

| 宽屏                     | 窄屏                             |
| ------------------------ | -------------------------------- |
| 活动栏 + 常驻树          | **底栏**（§3.1 四或五项）        |
| 树与主视图并排           | 树 = **全屏 sheet**              |
| 设置 / 连接 / 访问用弹窗 | **全屏页 + 分组列表**            |
| 访问抽屉                 | 全屏访问页，提示区固定在选项下方 |

触控：长按 = 右键（含「访问…」）；预览默认全屏；返回键覆盖同步方向、筛选 sheet、访问页、连接向导。点击目标 ≥
44px。上传：相册/相机/文件选择器，不依赖拖放。

### 4.3 欢迎页降级

| 端      | 工作区                              | 连接云                                          |
| ------- | ----------------------------------- | ----------------------------------------------- |
| Desktop | 系统文件夹选择器                    | OAuth / Token 按连接器                          |
| Web     | FSA 或 OPFS；说明清站点数据可能丢库 | 部分云仅 Desktop OAuth 时，Web 禁用该连接并提示 |
| Mobile  | 应用沙箱；卸载会丢库                | 同上；大文件/视频流能力不足时在连接卡片提示     |

### 4.4 Desktop / Web 差异（壳，不是第二套产品）

- Desktop：拖放、右键「访问… / 同步到…」；快捷键 `/` 搜索、`Ctrl+,`
  设置、`Ctrl+Shift+L` 日志；可选 push/pull 快捷键。
- Web：PWA 安装条放 `platforms/`；同步/授权失败用 `ContentFeedback` + 重试。
- 断点仍用 REF-601：`<768` / `768–1024` / `>1024`。Electron 缩放走同一 CSS。

## 六、落地批次（按现行需求重排）

实现仍最小 diff；业务在 `apps/pixuli` + `@pixuli/ui`；平台差在 `src/platforms/`
与 CSS；**provider 无 UI**，只提供能力位给界面。

| 批次                | 范围                                                       | 覆盖需求                       | 目的                                     |
| ------------------- | ---------------------------------------------------------- | ------------------------------ | ---------------------------------------- |
| **A. 窄屏壳**       | 活动栏→底栏；树→sheet；设置/连接/访问全屏                  | 三端共用                       | 否则阶段二在 Mobile 无法用               |
| **B. 资源库主路径** | 照片→资源库；类型筛选；banner 同步徽章；多选底栏           | F-ASSET 部分、F-CONN-04 可见性 | 阶段一不回退，主路径可扩展类型           |
| **C. 连接升格**     | 连接页 + 能力摘要；GitHub/Gitee 填满；向导三步             | F-CONN-01～03                  | 存储不再藏在设置里                       |
| **D. 访问控制**     | 本地/远程分列面板；禁用+三要素提示；发布总览；复制链接打通 | F-ACCESS-01～04                | **阶段二核心**；先在 Gitee/GitHub 上跑通 |
| **E. 类型补齐**     | PDF 预览、视频播放/占位；工具对非图禁用                    | F-ASSET-01～03                 | 同库不只图片                             |
| **F. 新云 UI**      | OneDrive / Google Cloud 连接与分享分支文案                 | F-CONN-02、F-ACCESS-02         | 能力位驱动，少写死品牌                   |
| **G. 工具与 AI**    | 恢复压缩/转换入口；AI 占位                                 | 阶段一工具 + REF-604           | 可发现，不挡 D                           |
| **H. 性能**         | 虚拟滚动                                                   | REF-603                        | 视频/PDF 缩略 + Mobile WebView           |
| **V. 品牌视觉**     | 紫/青 token；Welcome / Empty / Loading 对齐 Logo           | [07](./07-brand-visual-ui.md)  | 与 IA 批次并行，先换色再换插画           |

推荐顺序：**A → B → C →
D**，再 E/F；G/H 可与 D 并行。不要先做 OneDrive 再做访问面板——访问面板必须先在已有 Git 连接器上可用。

## 七、验收（UI）

| #   | 故事              | 通过标准                                                                 |
| --- | ----------------- | ------------------------------------------------------------------------ |
| U1  | 仅本地工作区      | 可浏览上传图片（阶段一）；访问里「仅本地」可用；远程档位提示需先添加连接 |
| U2  | GitHub/Gitee 图床 | 同步 pull/push + 公开 URL（若仓库/能力允许）；与今日博客场景等价         |
| U3  | 云不支持某访问档  | 选项禁用；提示含原因与替代；无假成功（F-ACCESS-03）                      |
| U4  | PDF 或视频入库    | 类型筛选可见；预览或打开；对 PDF 点压缩则禁用+提示                       |
| U5  | 窄屏              | `<768` 无常驻双栏 IDE；底栏可完成资源库 / 连接 / 访问 / 设置             |
| U6  | 三端步骤          | 同一旅程；壳层允许底栏 vs 活动栏、拖放 vs 相册                           |

阶段一回归：U1+U2 在 A–D 过程中不可破坏。
