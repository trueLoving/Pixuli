## 一、需求 → UI 必须讲清的四件事

| PRS          | 用户要完成的事                    | UI 必须出现的面                                     |
| ------------ | --------------------------------- | --------------------------------------------------- |
| F-ASSET-     | 同库管理图 / PDF / 视频           | **资源库**（类型筛选 + 按类型预览），不是「仅照片」 |
| F-CONN-      | 连上不同云，本地 SSOT + 可选同步  | **连接**（能力摘要 + 健康状态），配置在设置「同步」 |
| F-ACCESS-    | 控制对外访问：本地私有 / 远程发布 | **访问/发布**；本地与远程分列；配置在设置「访问」   |
| F-ACCESS-03  | 云不支持某档访问                  | **禁用 + 原因 + 替代**，禁止静默或假成功            |
| 阶段一不回退 | 现有 GitHub/Gitee 图床仍可用      | 新 IA 先用 GitHub/Gitee 填满，再加 OneDrive / GCS   |

原则（叠在 REF-601 上）：

| 原则                       | 落地                                             |
| -------------------------- | ------------------------------------------------ |
| **流程一致 / 壳层适配**    | 三端步骤相同；窄屏只改编排                       |
| **本地工作区优先**         | 浏览默认读本地；远程是柜子 + 发布通道            |
| **连接 ≠ 发布**            | 同步副本 ≠ 外网能打开                            |
| **配置进设置、外部只触发** | 仓库表与访问档位在设置；同步按钮只触发           |
| **降级显式**               | 端能力、云能力、类型不适用的工具，一律禁用并说明 |
| **可发现性**               | 上传、同步、设置有固定槽位；单文件操作在右栏     |

刻意不做：独立 RN
UI；恢复幻灯片/时间线/照片墙；为每种云单独做一套浏览界面；在 UI 里做云厂商控制台级 IAM。

## 三、建议信息架构（三端共用）

**工作台三部分**（步骤三端相同，排版按视口变；§3.5 为壳层 SSOT。连接器差异线框见
[06 §三](./06-asset-library-ui.md)）：

| 部分         | 职责                                     | 不放什么                  |
| ------------ | ---------------------------------------- | ------------------------- |
| **左：菜单** | 去哪、看哪一层范围                       | 单文件操作、仓库/访问表单 |
| **中：资源** | 浏览、搜索筛选、上传、多选、库级同步触发 | 完整连接/访问配置         |
| **右：文件** | 当前选中项的情况 + 对该文件的操作        | 设置策略表单、文件夹树    |

连接与访问的**配置**在设置内（分组：通用 / 同步 / 访问）。外部只**触发**：无远端 → 打开设置「同步」；已配置 → 选择同步方向。右栏可显示发布摘要，改档位仍进设置。

### 3.1 一级导航

宽屏活动栏 / 窄屏底栏，**3** 个固定槽位（2026-08 收口）：

| 槽位 | 名称       | 对应需求                        | 行为                 |
| ---- | ---------- | ------------------------------- | -------------------- |
| 1    | **资源库** | F-ASSET                         | 进入中栏浏览         |
| 2    | **同步**   | F-CONN-04                       | **触发**（见上）     |
| 3    | **设置**   | 工作区、远端表、访问策略、语言… | 弹窗或全屏；内部分组 |

工具（压缩/转换）不占一级：从右栏「送入」或资源「更多」进入。文件夹树是左栏的范围选择，不是一级图标。

### 3.2 资源库主视图（F-ASSET）

Banner（宽屏一行 / 窄屏两行，搜索与库级操作同行）：

```text
[范围：图片|视频|PDF|全部]  [搜索+筛选]  [上传]  [视图]  [同步]
```

| 建议     | 说明                                                              |
| -------- | ----------------------------------------------------------------- |
| 类型范围 | 默认图片；一键切视频 / PDF / 全部（F-ASSET-01）                   |
| 预览     | 图：现预览层；视频：播放或占位；PDF：内嵌或系统打开（F-ASSET-02） |
| 角标     | **本地可见性** + **同步态** +（若已发布）**远程档位**             |
| 多选     | 见 §3.5.4；动作在中栏底条，不进设置                               |
| 中屏密度 | 搜索可收为图标，避免与上传、同步抢宽                              |

上传按 MIME 分流：图走现确认流；PDF/视频走简表+预览；不支持类型仍可入库为「其他文件」。

卡片以**选中**为主，不堆单文件图标。双击/点缩略图可全屏预览；编辑、复制、删除等到右栏。

### 3.3 连接（F-CONN）

**落地位置**：设置 → **同步** 分组（表格 + 添加仓库），不是一级导航。

每条连接必须能读懂：

- 服务与位置（如 Gitee `owner/repo`、OneDrive 文件夹）
- **能力**：同步 / 公开 URL / 分享链接 / ACL / 大文件流（来自 manifest，禁止按
  `pluginId` 写死文案）
- **健康**：待推送、冲突、上次同步
- 操作：设为默认同步目标、编辑、断开

向导三步：选服务 → 授权与位置 → 用途（仅备份同步 / 默认同步 /
**允许作为发布通道**）。

GitHub/Gitee 先填满能力展示；OneDrive / Google Cloud 未落地时在画廊
**灰显 +「即将支持」**，不要假装已连接。

### 3.4 访问控制（F-ACCESS）— 本地与远程分列

**落地位置**：设置 → **访问** 分组。右栏只给摘要和「在设置中打开」。

```text
访问设置 — {文件名}
  本地
    ● 本机工作区可浏览（始终开启，不可关）
    ○ 不对外发布
  远程 — 通道：[Gitee owner/repo ▾]
    ○ 不在该云公开          （始终可选）
    ○ 仅链接可见            （连接器无 shareLink → 禁用）
    ○ 公开 URL / 可热链     （无 publicUrl → 禁用）
    ○ 过期 / 口令           （无能力 → 禁用）

  [提示区] 若有禁用项：标题 / 原因 / 替代 三要素

  [生成并复制链接]   [撤销远程访问]
```

规则：

1. **本地**：用户永远能看自己的资源；「仅本地」= 不发布，不是删文件。
2. **远程**：选项完全由该连接能力位驱动（F-ACCESS-02）。
3. **不支持**：禁用 + 三要素提示（F-ACCESS-03），不能只 toast。
4. 未同步到该通道却要发布 → 一次确认「先同步再发布」。
5. 复制公开链接时若尚未发布 → 打开设置访问分组，禁止静默 raw URL。

设置内保留已发布列表：通道、档位、复制、撤销。

### 3.5 三栏工作台（按视口）

断点与 REF-601 一致：窄屏 `<768`、中屏 `768–1024`、宽屏
`>1024`。Electron 同一套 CSS。

**PC / 宽屏是空间并排；Mobile
/ 窄屏是时间分层**（同一套三部分，同时只让一块占满主视野）。

#### 3.5.1 三部分职责（所有尺寸相同）

**左：菜单**

- 活动栏：资源库 / 同步 / 设置
- 文件夹树：当前浏览范围（路径；可选虚拟节点图片/视频/PDF）
- 同步：触发，不是配置页

**中：资源**

- 网格或列表 + banner（类型、搜索、筛选、上传、视图、同步）
- 多选底条（§3.5.4）
- 筛选结果、空态、加载、错误都在中栏

**右：文件（Inspector）**

- 未选中：空态「在中间点选一个文件」
- 选中 1 项：**情况**（缩略图、名称、尺寸/大小、日期、文件夹、同步态、发布档位只读）+
  **操作**（编辑元数据、复制已发布链接、分享、打开、删除；图片可送入压缩/转换；未发布则「去设置发布」）
- 选中 N 项：改为批量摘要（见 §3.5.4），不再展示单文件表单
- 全屏预览弹层可保留，只负责放大看图，不作为主操作区

#### 3.5.2 宽屏 `>1024`（左中右并排）

```text
┌────────┬──────────┬──────────────────────┬─────────────┐
│ 活动栏 │ 文件夹树  │  中：banner           │ 右：Inspector│
│ 资源库 │ 全部/路径 │  搜索 筛选 上传 视图 同步│ 文件情况     │
│ 同步   │ …        │──────────────────────│ 单文件操作   │
│ 设置   │          │  网格 / 列表          │             │
│        │          │  多选底条（若多选）    │ 或「已选 N」 │
└────────┴──────────┴──────────────────────┴─────────────┘
```

- 右栏固定宽约 280–360px，高度随主壳，内容滚动
- 树可折叠；折叠后中栏变宽，右栏仍在
- 设置 / 同步方向仍为模态，盖在三栏之上

#### 3.5.3 中屏 `768–1024`

优先 **两栏可视 + 第三栏按需**：

- 默认：活动栏（可更窄）+ 中栏网格；树收起，用按钮打开
- 选中文件后：右栏滑出或挤占中栏右侧（中栏列数减少）
- 搜索可收为图标，点开展开；筛选不要和 Inspector 抢同一条工具带

宽度刚过 768 时允许暂时隐藏树，**不要**三栏同时极窄。

#### 3.5.4 窄屏 `<768`（底栏 + 主屏 + sheet）

不要三栏缩小版，不要汉堡里塞菜单+树+详情。

```text
┌─────────────────────────┐
│ 中：资源（默认全屏）       │
│ banner / 网格            │
│ 多选底条（多选时，在底栏之上）│
├─────────────────────────┤
│ 资源库 │ 同步 │ 设置     │  ← 左菜单 = 底栏（常驻）
└─────────────────────────┘
```

叠层（后进先关，系统返回键同一顺序）：

| PC 的栏         | 窄屏                       | 如何出现                           |
| --------------- | -------------------------- | ---------------------------------- |
| 左：菜单        | 底栏 3 项                  | 常驻                               |
| 左：文件夹树    | 全宽 sheet                 | 点「文件夹」；选完即关             |
| 中：资源        | 默认主屏                   | 打开即在此                         |
| 右：文件        | **半屏 sheet，可上拉全屏** | **点选一张**之后；上沿仍能看到网格 |
| 设置 / 访问配置 | 全屏页                     | 底栏设置；复制未发布链接亦然       |
| 全屏看图        | 全屏预览                   | sheet 内点缩略图再进入             |

手势对应：

| 动作          | 宽屏         | 窄屏                                                    |
| ------------- | ------------ | ------------------------------------------------------- |
| 换范围        | 点左树       | 文件夹 sheet                                            |
| 浏览 / 筛选   | 中栏         | 主屏；筛选用独立 sheet，勿与 Inspector 叠成两个底 sheet |
| 看这个文件    | 右栏         | 点选 → 详情 sheet                                       |
| 放大看        | 预览弹窗     | sheet 点图 → 全屏预览                                   |
| 库级同步      | 中栏或活动栏 | 底栏同步                                                |
| 配仓库 / 访问 | 设置         | 底栏设置                                                |
| 多选          | Ctrl/Shift   | 长按进入多选                                            |

触控目标 ≥
44px。上传走相册/相机/文件选择器。长按 = 右键（可含「在设置中访问」）。

#### 3.5.5 搜索与筛选（库级，永远在中栏）

筛选改变的是**中间那批资源**，不是右栏里的一个文件。

|                          | 宽屏                                     | 窄屏                                                                |
| ------------------------ | ---------------------------------------- | ------------------------------------------------------------------- |
| 关键词搜索               | banner 输入框；`/` 聚焦（Desktop）       | banner 输入框；无全局 `/`                                           |
| 类型范围                 | banner chip                              | banner 一行 chip，可横滑                                            |
| 高级筛选（日期、标签等） | banner 旁面板或下拉                      | **独立筛选 sheet**（与文件夹 sheet、详情 sheet 互斥：同时只开一个） |
| 当前过滤摘要             | banner 下一条可清除的 chip               | 同左，贴在网格顶                                                    |
| 无结果                   | 中栏空态 + 清除筛选                      | 同左                                                                |
| 与选中的关系             | 过滤后若当前文件不在结果中，清空右栏选中 | 关闭详情 sheet，回到网格                                            |

不要把筛选控件做到 Inspector 里。文件夹范围与类型/搜索是**与**关系：树选文件夹 ∩
banner 条件。

#### 3.5.6 批量操作（中栏底条，与右栏互斥）

进入多选：宽屏 Ctrl/Cmd+点、Shift 范围；窄屏长按进入，再点选追加。

|                   | 选中 0   | 选中 1                     | 选中 N≥2                                                                          |
| ----------------- | -------- | -------------------------- | --------------------------------------------------------------------------------- |
| 中栏              | 正常浏览 | 高亮该项                   | 网格高亮多项 + **底条**                                                           |
| 右栏 / 详情 sheet | 空态     | 单文件情况+操作            | **批量模式**：已选 N、范围提示（当前筛选+文件夹）                                 |
| 底条动作          | 无       | 可不显示底条（动作在右栏） | 下载、同步到…、删除；「访问…」打开设置并带入多选（若暂不支持多选发布则禁用+说明） |
| 压缩/转换         | —        | 右栏「送入」（仅图片）     | 底条：仅当全部为图片才可用，否则禁用+提示                                         |

窄屏多选底条画在系统底栏**之上**，不要挡住资源库/同步/设置。退出多选：取消、返回键、或选中数归零。

批量删除/下载作用于**当前选中且仍满足筛选**的集合；筛选变化时从选中集里丢掉已不可见的项，并更新 N。

## 四、壳层与三端适配（仍是 P0）

阶段二 IA 若直接铺成桌面三栏常驻，Mobile 会不可用。按 §3.5 改编排，槽位按 §3.1。

### 4.1 统一主壳

工作区模式 =
**唯一主壳**（Web/Desktop/Android）。旧侧栏仅无工作区平台降级并规划下线。

### 4.2 窄屏 `<768px`

以 §3.5.4 为准。摘要：

| 宽屏                   | 窄屏                                         |
| ---------------------- | -------------------------------------------- |
| 活动栏 + 常驻树 + 右栏 | **底栏**三项；树 / 详情 / 筛选均为 **sheet** |
| 设置弹窗               | **全屏页** + 分组列表                        |
| 访问配置               | 设置内全屏；提示区固定在选项下方             |

### 4.3 欢迎页降级

| 端      | 工作区                              | 连接云                                          |
| ------- | ----------------------------------- | ----------------------------------------------- |
| Desktop | 系统文件夹选择器                    | OAuth / Token 按连接器                          |
| Web     | FSA 或 OPFS；说明清站点数据可能丢库 | 部分云仅 Desktop OAuth 时，Web 禁用该连接并提示 |
| Mobile  | 应用沙箱；卸载会丢库                | 同上；大文件/视频流能力不足时在连接卡片提示     |

### 4.4 Desktop / Web 差异（壳，不是第二套产品）

- Desktop：拖放、右键「访问… / 同步到…」；快捷键 `/` 搜索、`Ctrl+,`
  设置、`Ctrl+Shift+L` 日志；可选 push/pull 快捷键。
- Web：PWA 安装条放 `platforms/`；同步/授权失败用 `ContentFeedback` + 重试。
- 断点仍用 REF-601：`<768` / `768–1024` / `>1024`。Electron 缩放走同一 CSS。

## 七、验收（UI）

| #   | 故事              | 通过标准                                                                          |
| --- | ----------------- | --------------------------------------------------------------------------------- |
| U1  | 仅本地工作区      | 可浏览上传图片；设置访问里「仅本地」可用；远程档位提示需先添加连接                |
| U2  | GitHub/Gitee 图床 | 同步 pull/push + 公开 URL（若仓库/能力允许）；与今日博客场景等价                  |
| U3  | 云不支持某访问档  | 选项禁用；提示含原因与替代；无假成功（F-ACCESS-03）                               |
| U4  | PDF 或视频入库    | 类型筛选可见；预览或打开；对 PDF 点压缩则禁用+提示                                |
| U5  | 窄屏              | `<768` 无常驻三栏；底栏资源库/同步/设置；详情与筛选为 sheet                       |
| U6  | 三端步骤          | 同一旅程；壳层允许底栏 vs 活动栏、拖放 vs 相册                                    |
| U7  | 宽屏三栏          | 左菜单、中资源、右文件；选中 1 项右栏有情况+操作                                  |
| U8  | 筛选 + 批量       | 过滤后中栏结果变化；多选底条；过滤掉的项退出选中；窄屏筛选与详情 sheet 不同时打开 |

阶段一回归：U1+U2 在后续批次中不可破坏。
