> **一句话**：本地优先的资源工作区。文件夹与文件的查询 / 添加 / 删除 / 修改 / 类型化工具**只改本机**；连接用于同步与发布通道；对外访问按云能力配置，不支持则
> **禁用并提示**。

本文只定 **UI 信息架构与交互**，不定 Provider API。

---

## 一、概念与硬规则

### 1.1 三个用户概念

```text
工作区（Vault）
  └── 资源（文件 + 元数据 + 预览）· 放在文件夹里
        ├── 连接（连到哪个存储、怎么同步）
        └── 发布（外界怎么打开）
```

| 概念       | 用户理解                         |
| ---------- | -------------------------------- |
| **工作区** | 本机本地库                       |
| **文件夹** | 本地路径容器；定浏览范围         |
| **连接**   | GitHub / Gitee / OneDrive / GCS… |
| **发布**   | 私有 / 仅链接 / 公开等对外档位   |

### 1.2 本地 vs 远端（硬规则）

| 操作                              | 范围           | 自动同步远端？             |
| --------------------------------- | -------------- | -------------------------- |
| 查询 / 浏览 / 预览                | 本地           | 否                         |
| 文件夹新建 / 重命名 / 移动 / 删除 | **仅本地**     | **否**                     |
| 文件添加 / 删除 / 改元数据 / 移动 | **仅本地**     | **否**                     |
| 压缩 / 转换（图片）               | **仅本地**产物 | **否**                     |
| **同步** pull / push              | 本地 ↔ 远端   | 是（**单独入口**）         |
| **发布** / 改可见性               | 按连接能力     | 显式发布流程，不是删改附属 |

确认文案写清「仅本机」。**不**在删改确认里勾选「同时删远端」。同步态可在 Inspector
**只读**展示。

### 1.3 设计原则

| 原则                     | 说明                                                             |
| ------------------------ | ---------------------------------------------------------------- |
| 本地工作区是主舞台       | 浏览与库内操作默认读/写本地                                      |
| 连接 ≠ 发布              | 同步副本 ≠ 外网能打开                                            |
| 文件夹定范围，查询再收窄 | 可见结果 = 当前文件夹 ∩ 查询                                     |
| 类型决定操作集           | 图片有压缩/转换；PDF 等无；禁用须说明                            |
| 降级显式                 | 云不支持的档位禁用 + 原因 + 替代                                 |
| 三端同一旅程             | 窄屏只改编排（见 [03](./03-three-platform-interaction-spec.md)） |

## 二、信息架构

宽屏：活动栏 + 文件夹树 + 主视图 +
Inspector。窄屏：底栏 + 文件夹 / 详情 sheet（互斥）。

```text
┌────────┬──────────────┬─────────────────────────┬────────────┐
│ 活动栏 │ 文件夹树     │ 主视图                   │ Inspector  │
│ 资源库 │ 全部         │ 范围 · 查询 · 添加 · 同步 │ 空/单/批   │
│ 连接*  │ ├ 相册/      │ 网格/列表（范围∩查询）   │            │
│ 发布*  │ └ 文档/      │                          │            │
│ 设置   │              │                          │            │
└────────┴──────────────┴─────────────────────────┴────────────┘
```

\*连接 / 发布可为一级，或 P0 放在设置 +
banner 入口（现行实现以后者为多）；产品叙事仍要「连接 ≠ 发布」。

| 区域      | 职责                                   |
| --------- | -------------------------------------- |
| 文件夹树  | 选范围；文件夹 CRUD（仅本地）          |
| 主视图    | 当前文件夹内文件；查询；添加；多选     |
| Inspector | 文件夹摘要 / 单文件 / 批量；类型化操作 |

同步：banner 徽章或连接页触发，**不**占用与「连接」重复的一级图标亦可。

## 三、文件夹（仅本地）

| 操作                 | 要点                                                                     |
| -------------------- | ------------------------------------------------------------------------ |
| 选中                 | 设当前范围；建议清多选；清已生效查询、可留草稿                           |
| 新建 / 重命名 / 移动 | 仅本地；重命名时更新索引内相对路径                                       |
| 删除                 | 确认：「仅本机，含 N 个文件，不同步删远端」；当前范围被删则回退父级/全部 |
| 空文件夹             | Empty：添加文件 / 新建子文件夹（区别于查询无结果、整库空）               |
| 拖放（桌面/Web）     | 文件或文件夹移动仅本地；系统文件拖入 = 添加确认                          |

选中文件夹且无文件多选时：Inspector 显示路径与文件夹操作，**不**显示图片压缩。

**建议默认**：主视图只列**本层文件**（不含深层），与「全部」区分清楚。

## 四、查询

- 搜索框为**草稿**；**Enter / 搜索**才生效。
- `?` 语法帮助；清除 = 回到当前文件夹下全部文件。
- 语法：裸词/`name:`（AND）；`kind:`（OR：`image`/`video`/`pdf`/`other`）；`size:`（AND，支持比较与单位）。
- 示例：`cover kind:image size:>1mb`
- 规划：`tag:`、`path:`、日期字段。排序用独立控件。
- **不做**独立筛选面板 + chip 条。

可选：「在全部中搜索」忽略树范围并提示。

## 五、添加 · 删除 · 修改（仅本地）

### 5.1 添加

1. 选文件 / 拖放 → 短确认（目标文件夹默认 = 当前范围）
2. 写入本地 + 索引 → 关浮层

| 类型        | 确认                           |
| ----------- | ------------------------------ |
| 图片 / 视频 | 预览、名称、描述、标签、文件夹 |
| PDF / 其它  | 文件名、可选描述/标签、文件夹  |

主按钮文案：**「添加到工作区」**。成功 toast
**不**写已同步到云。远端一致 → 用户点同步。

### 5.2 删除

单选 / 多选 / 键盘 Delete。确认必须含「仅本机，不会同步删除远端」。文件夹删除见 §三。

### 5.3 修改

| 可改                         | 只读                                        |
| ---------------------------- | ------------------------------------------- |
| 名称、描述、标签、移动文件夹 | 尺寸、体积、MIME、时间、同步态、URL、可见性 |

保存只写本地。批量标签 / 移动为规划项。可见性走**发布**，不属库内编辑。

## 六、文件操作：按类型

| 能力                                  | 图片 | 视频 | PDF |   其它   |
| ------------------------------------- | :--: | :--: | :-: | :------: |
| 预览 / 打开                           |  ✅  |  ✅  | ✅  | 系统打开 |
| 元数据编辑 / 移动 / 复制链接\* / 分享 |  ✅  |  ✅  | ✅  |    ✅    |
| **压缩 / 格式转换**                   |  ✅  |  ❌  | ❌  |    ❌    |
| AI 标签（如 Desktop）                 |  ✅  |  ❌  | ❌  |    ❌    |
| 删除（仅本地）                        |  ✅  |  ✅  | ✅  |    ✅    |

\*复制链接不改发布策略；未发布行为与 §八 对齐。矩阵为 ❌ 则隐藏或禁用并说明原因。

**压缩 / 转换**：仅图片；本地处理；替换或另存仍在本地；不自动同步。混合多选时跳过非图片并明示。

| 选中           | Inspector                       |
| -------------- | ------------------------------- |
| 0 + 树为文件夹 | 文件夹摘要                      |
| 1 文件         | 预览 + 信息 + 类型化操作 + 删除 |
| ≥2             | 批量摘要；操作按类型；批量删除  |

## 七、连接

连接器能力位（manifest，UI 只读）：`sync.push/pull`、`publicUrl`、`shareLink`、`acl`、`streaming`、`listPublic`
等。

**列表卡**：服务 · 位置 · 能力摘要 · 同步健康 · 默认同步 / 同步 / 编辑 / 断开。

**添加向导**（三步一致）：选服务 → 授权与位置 → 用途（备份 / 默认同步 / 发布通道）。

GitHub/Gitee：图床与公网 raw 强、大视频与细 ACL 弱。OneDrive 等：分享强、稳定 CDN
URL 弱。仅本地：发布入口禁用并提示先添加连接。

## 八、发布与访问

**同步** = 远端有无副本；**发布** = 外界有无合法打开方式。

| 档位      | 含义                     |
| --------- | ------------------------ |
| 私有      | 仅本机；无外链           |
| 仅链接    | 有链接可开；不进公开列表 |
| 公开      | 稳定公网 URL             |
| 定时/口令 | P1+，视连接器            |

发布抽屉：选通道（仅有 URL 能力的连接）→ 可见性 → 生成并复制。通道不支持 →
**禁用 + 原因 + 替代**（F-ACCESS-03）。目录公开须二次确认。

发布总览：资源、通道、档位、链接、撤销。收权须说明 CDN/缓存可能延迟。

## 九、关键旅程

1. 开工作区 → 本地添加文件到文件夹（不同步）。
2. 需要远端 → 添加连接 → **同步**。
3. 需要外链 → **发布** → 选档位 → 复制。
4. 库内删改 → 仅本地；再同步才影响远端。
5. `kind:image size:>1mb` → 多选压缩 → 本地产物。

## 十、验收

| #   | 通过标准                              |
| --- | ------------------------------------- |
| L1  | 添加/删/改确认与结果均为仅本地        |
| L2  | 文件夹范围 ∩ 查询正确；空态文案可区分 |
| L3  | 图片有压缩入口；PDF 无或禁用有原因    |
| C1  | 连接能力可见；不支持档位禁用有替代    |
| P1  | 发布与同步入口分离；可撤销并说明后果  |
| X1  | 三端步骤一致；窄屏 sheet              |
