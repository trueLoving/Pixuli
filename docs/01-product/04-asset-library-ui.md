> **一句话**：本地文件库 + 显式同步 + **能力驱动**的外链。文件夹与文件的查询 /
> 添加 / 删除 / 修改 / 类型化工具**只改本机**；连接用于同步通道；对外访问按云能力配置，不支持则
> **禁用并提示**（不画空壳档位）。

本文定 **UI 信息架构、硬规则、默认行为与实现优先级**，不定 Provider API。

用户只记三句：

1. 改库 = 只动本机
2. 要远端一样 → 点同步
3. 要给人打开 → 点发布（有能力才亮）

---



## 一、概念与硬规则



### 1.1 用户概念

```text
工作区（Vault）
  └── 资源（文件 + 元数据 + 预览）· 放在文件夹里
        ├── 连接（连到哪个存储、怎么同步）—— 设置里配置
        └── 发布（外界怎么打开）—— 有能力才出现
```


| 概念      | 用户理解                               |
| ------- | ---------------------------------- |
| **工作区** | 本机本地库                              |
| **文件夹** | 本地路径容器；定浏览范围                       |
| **连接**  | GitHub / Gitee / …（设置中管理；P0 不占活动栏） |
| **发布**  | 按连接能力生成外链；不是库内「可见性」编辑字段            |




### 1.2 本地 vs 远端（硬规则）


| 操作                    | 范围        | 自动同步远端？       |
| --------------------- | --------- | ------------- |
| 查询 / 浏览 / 预览          | 本地        | 否             |
| 文件夹新建 / 重命名 / 移动 / 删除 | **仅本地**   | **否**         |
| 文件添加 / 删除 / 改元数据 / 移动 | **仅本地**   | **否**         |
| 压缩 / 转换（图片）           | **仅本地**产物 | **否**         |
| **同步** pull / push    | 本地 ↔ 远端   | 是（**单独入口**）   |
| **发布** / 改可见性         | 按连接能力     | 显式发布流程，不是删改附属 |


确认文案写清「仅本机」。**不**在删改确认里勾选「同时删远端」。同步态在条目 /
Inspector **只读**展示。

**添加 ≠ 上传到云**：「添加 / 添加到工作区」只表示入库本机；远端一致只通过「同步」。禁止「上传成功 / 已同步到云」类文案暗示已上云。

### 1.3 设计原则


| 原则           | 说明                                                      |
| ------------ | ------------------------------------------------------- |
| 本地工作区是主舞台    | 浏览与库内操作默认读/写本地                                          |
| 连接 ≠ 发布      | 同步副本 ≠ 外网能打开                                            |
| 文件夹定范围，查询再收窄 | 可见结果 = 当前文件夹 ∩ 查询                                       |
| 类型决定操作集      | 图片可压缩/转换；PDF 等无；无能力则**隐藏**或禁用并说明                        |
| 能力驱动 UI      | 无 `shareLink` / `streaming` 等则不画对应控件与空档位                |
| 降级显式         | 不支持时：原因 + 替代（先加连接 / 换连接）                                |
| 三端同一旅程       | 窄屏只改编排（见 [03](./03-three-platform-interaction-spec.md)） |
| 同步不锁库        | 同步进行中可继续浏览 / 添加 / 编辑；改过的文件结束后再同步一次即可                    |
| 主路径宜薄        | 完整矩阵可进 P1；半实现壳层（死按钮、空档位、未接线栏）比没有更吵                      |




### 1.4 添加与同步：两条通道

```text
选文件（多类型 / 批量）
  → 短确认浮层
  → 写入本地 + 索引 → 立刻关浮层
  → 活动栏待推送角标 +N（若有连接）
  → 用户需要远端一致时 → 点「同步」
       └─ 同步中不锁库；期间又改本地 → 完成后仍待推送 → 再同步一次
```


| 通道     | 用户动作     | 是否碰远端 | UI 要求                         |
| ------ | -------- | ----- | ----------------------------- |
| **添加** | 「添加到工作区」 | 否     | 短确认；提交后关浮层；进度若需则在壳层，不占模态      |
| **同步** | 活动栏「同步」  | 是     | 青色 busy；角标待推送 N；**禁止**全屏锁死主界面 |


技术上可将变更入 push 队列，产品叙事仍是「添加完成 = 已在本地」。

## 二、信息架构

宽屏：活动栏 + 文件夹树 + 主视图 + Inspector。
窄屏：底栏 + 文件夹 / 详情 sheet（互斥）。

### 2.1 主路径（默认）

```text
┌────────┬──────────────┬─────────────────────────┬────────────┐
│ 活动栏 │ 文件夹树     │ 主视图                   │ Inspector  │
│ 资源库 │ 全部         │ 范围 · 查询 · 添加       │ 空/单/批   │
│ 同步 N │ ├ 相册/      │ 列表（本层 ∩ 查询）      │            │
│ 设置   │ └ 文档/      │                          │            │
└────────┴──────────────┴─────────────────────────┴────────────┘
```


| 区域        | 职责                                    |
| --------- | ------------------------------------- |
| 活动栏       | **资源库** · **同步**（角标 N / busy）· **设置** |
| 文件夹树      | 选范围；文件夹 CRUD（仅本地）                     |
| 主视图       | 本层文件；查询；添加；多选                         |
| Inspector | 文件夹摘要 / 单文件 / 批量；类型化操作                |


- **连接 / 发布不占活动栏一级**（P0）：在设置中管理连接；选中文件后按能力露出发布 /
复制链接。叙事仍须「连接 ≠ 发布」。
- 同步：活动栏触发；busy 用**青色**（见 [05 品牌](./05-brand-visual-ui.md)），与选中紫条区分。
- 主视图默认**列表**；网格切换为 P1。
- 上下文：选中文件 → 复制链接 / 发布（有能力才亮）/ 删除。



### 2.2 可升层（非默认）

连接 / 发布升为活动栏一级、完整同步任务抽屉等 → 见 §十一 P1 / 延后；升层前须产品确认。

## 三、文件夹（仅本地）


| 操作         | 要点                                          |
| ---------- | ------------------------------------------- |
| 选中         | 设当前范围；P1 建议清多选、清已生效查询（可留草稿）                 |
| 新建 / 重命名   | 仅本地；重命名时更新索引内相对路径                           |
| 移动         | 仅本地；P0 以对话框 / 编辑内选目标为主；树内拖放为 P1+            |
| 删除         | 确认：「仅本机，含 N 个文件，不同步删远端」；当前范围被删则回退父级/全部      |
| 空文件夹 / 整库空 | Empty **必须有 CTA**：添加文件 / 新建子文件夹（区别于查询无结果）   |
| 拖放（桌面/Web） | **P0**：系统文件拖入 = 打开添加确认。库内条目拖到树 / 拖文件夹 = P1+ |


选中文件夹且无文件多选时：Inspector 显示路径与摘要；文件夹操作可在树右键，P1 可沉入 Inspector。**不**显示图片压缩。

**默认**：主视图只列**本层文件**（不含深层），与「全部」区分清楚。

## 四、查询

- 搜索框为**草稿**；**Enter / 搜索**才生效。
- `?` 语法帮助；清除 = 回到当前文件夹下全部文件。
- 语法：裸词 / `name:`（AND）；`kind:`（OR：`image` / `video` / `pdf` / `other`）；`size:`（AND，支持比较与单位）。
- 示例：`cover kind:image size:>1mb`
- **主路径可选**：轻量类型切换（全部 / 图片 / PDF），语法进 `?`，二者并存。
- **不做**独立筛选面板 + chip 条。
- 规划（延后）：`tag:`、`path:`、日期字段。排序用独立控件。
- P1 可选：「在全部中搜索」忽略树范围并提示。

## 五、添加 · 删除 · 修改（仅本地）



### 5.1 添加（短确认 → 仅本地 → 关浮层）

支持**多类型**与**批量**；确认后**不阻塞**其它库内交互。

#### 流程

1. 选文件 / 多选 / 拖放（系统文件拖入 = 打开确认）。
2. **短确认浮层**（目标文件夹默认 = 当前树范围）。
3. 主按钮 **「添加到工作区」** → 写入本地文件 + 索引。
4. **立刻关浮层**；toast：**已添加到工作区（仅本机）**。
5. 列表出现条目（短暂「处理中」在条目/壳层表达，不锁模态）。
6. 需要远端一致 → 用户之后点 **同步**（见 §5.4）。

```text
选文件 → 短确认 → 关浮层 → 本地可见
                      └→ 待推送 +N → 用户点同步 → 远端
```



#### 确认层字段（按类型）


| 类型       | 确认内容            |
| -------- | --------------- |
| 图片 / 视频  | 预览、名称、描述、标签、文件夹 |
| PDF / 其它 | 文件名、可选描述/标签、文件夹 |


混选一批：同一确认壳；列表带类型角标；共享目标文件夹与可选统一描述/标签。不支持的预处理（如压缩）不在添加确认里强行做。

#### 添加后完善元数据


| 规则            | 说明                            |
| ------------- | ----------------------------- |
| **默认关闭**逐张完善  | 避免大批量添加时打断                    |
| 自动进入逐张        | 批量 **≤3**，**或** 确认层勾选「添加后编辑」  |
| 逐张栏           | 选中首张；Inspector：上一张 / 下一张 / 完成 |
| 批摘要点文件名切单文件编辑 | **始终保留**                      |
| 精准元数据主路径      | 入库后单文件编辑                      |




#### 明确不做

- 添加浮层内跑完整远端上传进度并锁死界面。
- 添加成功文案暗示已上云。
- 因「正在添加」而禁用搜索、换文件夹、打开其它文件。



### 5.2 删除

单选 / 多选 / 键盘 Delete。确认必须含「仅本机，不会同步删除远端」。文件夹删除见 §三。

### 5.3 修改


| 可改              | 只读                        |
| --------------- | ------------------------- |
| 展示名、描述、标签、移动文件夹 | 尺寸、体积、MIME、时间、同步态、URL、发布态 |




#### 展示名 vs 磁盘路径

- 用户编辑的是 **展示名（**`name`**）**，默认**不是**重命名磁盘文件（「重命名文件」若另开，须单独入口）。
- 列表 / Inspector **主标题用** `name`；路径 basename（含 timestamp 前缀）仅作次要信息。
- 同步 round-trip **不得**用远端 basename 覆盖已编辑的展示名。

保存只写本地。


| 能力       | 优先级                     |
| -------- | ----------------------- |
| 单文件移动文件夹 | **P0**（编辑弹层或 Inspector） |
| 批量标签     | 已可做                     |
| 批量移动     | P1                      |
| 可见性      | 走**发布**，不属库内编辑          |


同步进行中亦可修改：结果仍以本地为准；见 §5.4。

### 5.4 同步、待推送与「再同步一次」

**同步**是显式动作（活动栏），把本地变更 pull/push 到连接；与「添加」分离。

#### 壳层反馈（对外默认）


| 元素             | P0 行为                                         | P1+              |
| -------------- | --------------------------------------------- | ---------------- |
| 活动栏「同步」        | 空闲可点；进行中 **青色** busy；角标 = **待推送数 N** 或「同步中」   | —                |
| 条目 / Inspector | 只读 **两态**：`仅本地` / `已同步`（读 vault；待推送并入仅本地或轻角标） | 四态：待同步 / 同步中     |
| 任务抽屉           | 不做                                            | 待推送列表、进度、失败重试    |
| streaming 暂停续传 | 无能力则 **不露出**                                  | 有 `streaming` 再露 |




#### 同步中不锁库（硬规则）

- **禁止**全屏遮罩或禁用整个资源库。
- 可轻提示：「同步进行中；若继续修改，完成后请再同步一次。」
- **不**为防竞态而冻结全库。



#### 同步期间又改了同一文件

1. t1 开始推送文件 A。
2. t2 用户再次修改 A → **只写本地**，界面立刻为新内容。
3. t1 结束后：若本地已新于远端 → 仍为待推送（对外可显示「仅本地」）。
4. 用户再点 **同步** → 远端对齐到最新本地。

用户心智：**本地随时能改；远端以最近一次成功同步为准；不够新就再同步一次。**

#### 中断与断点


| 能力            | 交互                                             |
| ------------- | ---------------------------------------------- |
| 取消「写入本地」未完成项  | 始终可做；未完成则不落索引或不保留半成品                           |
| 取消本次同步推送      | 可做；本地文件保留，回到待推送                                |
| 暂停 / 继续（字节续传） | **仅当** manifest 具备 `streaming`（或等价）时露出；否则不画该控件 |


GitHub / Gitee：按「无字节断点」设计。

#### 单文件状态机（引擎完整；UI 默认折叠）

```text
添加确认
  → （可选）写入中
  → 仅本地
  →（入队）待推送
  → 用户点同步 → 同步中
       ├─ 成功且本地未再改 → 已同步
       └─ 期间或之后本地又改过 → 待推送（再同步即可）
```

P0 UI 可将「待推送 / 同步中」折叠进「仅本地」+ 活动栏 busy/N；P1 再展开四态。

## 六、文件操作：按类型


| 能力                     | 图片  | 视频  | PDF | 其它   |
| ---------------------- | --- | --- | --- | ---- |
| 预览 / 打开                | ✅   | ✅   | ✅   | 系统打开 |
| 元数据编辑 / 移动 / 复制链接 / 分享 | ✅   | ✅   | ✅   | ✅    |
| **压缩 / 格式转换**          | ✅   | ❌   | ❌   | ❌    |
| AI 标签（如 Desktop）       | ✅*  | ❌   | ❌   | ❌    |
| 删除（仅本地）                | ✅   | ✅   | ✅   | ✅    |


 AI 未接入前 **隐藏** 入口，避免常驻 disabled。

复制链接不改发布策略；未发布行为与 §八 对齐。矩阵为 ❌ 则隐藏或禁用并说明原因。

**压缩 / 转换**：仅图片；本地处理；替换或另存仍在本地；不自动同步。混合多选时跳过非图片并明示。


| 入口               | 优先级           |
| ---------------- | ------------- |
| 工具页压缩 / 转换       | 主路径；总开关打开后可用  |
| Inspector「发送到压缩」 | P1；库内不另造压缩工作台 |



| 选中        | Inspector            |
| --------- | -------------------- |
| 0 + 树为文件夹 | 文件夹摘要                |
| 1 文件      | 预览 + 信息 + 类型化操作 + 删除 |
| ≥2        | 批量摘要；操作按类型；批量删除      |

## 七、连接

连接器能力位（manifest，UI 只读）：`sync.push/pull`、`publicUrl`、`shareLink`、`acl`、`streaming`、`listPublic`
等。

**入口（P0）**：设置 → 连接列表；不占活动栏一级。

**列表卡**：服务 · 位置 · 能力摘要 · 同步健康 · 设默认同步目标 / 编辑 / 断开。卡内「立即同步」可选；主同步仍以活动栏为准。

**添加向导**：选服务 → 用途（备份 / 默认同步 / 发布通道）→ 授权与位置。P1 收成同一壳三步进度条。

GitHub / Gitee：图床与公网 raw 强、大视频与细 ACL 弱。OneDrive / GCS 等：在未注册官方 provider 前仅「即将」展示，**不可创建**。仅本地：发布入口禁用并提示先添加连接。

## 八、发布与访问

**同步** = 远端有无副本；**发布** = 外界有无合法打开方式。

### 8.1 能力驱动档位（不要空壳）

```text
有 publicUrl     → 「生成公网链接 / 复制 / 撤销」
有 shareLink/acl → 再展开「仅链接」等
有 timedAccess   → 再展开定时 / 口令
无任何 URL 能力  → 入口禁用 + 原因 + 替代
```


| 档位（有能力时） | 含义           |
| -------- | ------------ |
| 私有       | 仅本机；无外链      |
| 仅链接      | 有链接可开；不进公开列表 |
| 公开       | 稳定公网 URL     |
| 定时 / 口令  | 延后，视连接器      |


发布抽屉 / 选中上下文：选通道（仅有 URL 能力的连接）→ 可见性（按能力）→ 生成并复制。通道不支持 →
**禁用 + 原因 + 替代**（F-ACCESS-03）。

目录公开二次确认：仅当连接支持**目录级发布**时再做；文件级 raw（GitHub/Gitee 典型）不提前堆确认流。

发布总览（设置）：资源、通道、档位、链接、撤销。收权须说明 CDN/缓存可能延迟。P1 补全列与列表内撤销。

## 九、关键旅程

1. 开工作区 → **添加**文件到文件夹（仅本地，浮层即关）。
2. 需要远端 → 设置中添加连接 → **同步**（不锁库；活动栏见 N）。
3. 同步中又改了某文件 → 结束后仍待推送 → **再同步一次**。
4. 需要外链 → **发布**（有 `publicUrl` 等）→ 复制。
5. 库内删改 → 仅本地；再同步才影响远端。
6. （P1）`kind:image size:>1mb` → 发送到压缩 → 本地产物。

## 十、验收



### 10.1 旅程验收（排期优先）


| #   | 通过标准                                     |
| --- | ---------------------------------------- |
| J1  | 开工作区 → 添加 → 立刻可见 → toast 仅本机；未点同步则远端无新文件 |
| J2  | 编辑展示名 → 列表主标题为展示名 → push/pull 后展示名仍在     |
| J3  | 活动栏可见待推送 N → 同步成功 → 条目已同步；同步中可继续浏览/编辑    |
| J4  | 有 `publicUrl` 时可发布并复制；无能力则禁用并说明；与同步入口分离  |
| J5  | 空文件夹有添加/新建 CTA；单文件可移动到另一文件夹（仅本机）         |


压缩入口、完整四态、任务抽屉、逐张完善默认开 → **不阻塞** J1–J5。

### 10.2 语义验收（回归）


| #   | 通过标准                               |
| --- | ---------------------------------- |
| L1  | 添加/删/改确认与结果均为仅本地                   |
| L2  | 文件夹范围 ∩ 查询正确；空态文案与 CTA 可区分         |
| L3  | 压缩总开关打开后：图片有入口；PDF 无或禁用有原因         |
| L4  | 多类型 / 批量添加：确认后浮层关闭，可继续浏览与再添加       |
| L5  | 未点同步前远端无新文件；同步中可改文件，结束后待推送 → 再同步对齐 |
| C1  | 连接能力可见；不支持档位不画空壳；禁用有替代             |
| P1  | 发布与同步入口分离；可撤销并说明后果                 |
| X1  | 三端步骤一致；窄屏 sheet                    |
